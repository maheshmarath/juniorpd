# Vivan's Junior Product Designer Academy

A buildless, static 84-day course website. Open `index.html` locally to preview it, or publish the four site files on GitHub Pages. No npm, server, account, or build step is required.

## Publish on GitHub Pages

1. Create a new public GitHub repository (for example, `vivan-academy`).
2. Upload `index.html`, `style.css`, and `lessons.js` and `app.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then save.
5. Wait for GitHub to show the site URL, usually `https://YOUR-USERNAME.github.io/vivan-academy/`. Open it and start Day 1.

All links use URL fragments, so the site works at a GitHub Pages project path without configuration. Update the files in the repository to publish changes.

## Progress and privacy

Progress, notes, lesson completion, quiz attempts, streaks, and activity history are stored in the current browser's `localStorage`. Nothing is sent to a server. Progress does **not** sync across devices or browsers. Clearing browser data or using private browsing can erase it. Keep the same browser and device for continuity.

The dashboard counts unique calendar days with lesson activity as attempted days. Missed days are past days since the first attempt without activity. The current streak continues if the last attempt was today or yesterday. Lessons can be completed in any order.

Each lesson includes a related YouTube video, a worked example, a guided build, an independent challenge, a success check, and a short quiz. Videos open on YouTube in a new tab; an adult can choose how Vivan watches them. Some foundation videos recur when several lessons build on the same skill.

## Safety

An adult should help with Tinkercad account setup and supervise cutting tools and any 3D printer. Paper and cardboard prototypes work for lessons that mention printing.
